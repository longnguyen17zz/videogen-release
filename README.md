# VideoGen AI — bản phát hành

Repo này **chỉ chứa file cài đặt (.exe)** của VideoGen AI (bản native cho Windows). Mã nguồn nằm ở repo riêng (private).

**Tải bản mới nhất:** vào [Releases](../../releases), tải file `.exe` mới nhất rồi chạy.

- Cần Windows 10 trở lên (64-bit).
- Mỗi lần có bản mới, app sẽ tự báo khi mở lên — bấm vào thông báo để tải bản mới.
